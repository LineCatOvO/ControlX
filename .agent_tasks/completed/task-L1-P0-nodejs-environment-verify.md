## 三、执行计划

### 3.1 操作步骤

**步骤 1：验证 Node.js 版本**
```bash
node --version
```
**预期输出**：v20.x.x 或更高版本（LTS）

**步骤 2：验证 npm 版本**
```bash
npm --version
```
**预期输出**：10.x.x 或更高版本

**步骤 3：验证 pnpm 安装**
```bash
pnpm --version
```
**预期输出**：8.x.x 或 9.x.x

**步骤 4：验证 Node.js LTS 状态**
```bash
node -e "console.log(process.release.lts)"
```
**预期输出**：非 null 值（如 "Iron"、"Jod" 等 LTS 代号）

### 3.2 验证步骤

**验证命令**：
```bash
# 综合验证脚本
node --version && npm --version && pnpm --version
```

**预期输出**：
```
v20.x.x
10.x.x
8.x.x 或 9.x.x
```

### 3.3 回滚方案

**回滚条件**：环境验证失败
**回滚操作**：
- 如 Node.js 版本不满足：安装 Node.js 20+ LTS
- 如 pnpm 未安装：执行 `npm install -g pnpm`
