## 验收标准

### 测试通过标准

| 测试类型 | 通过率要求 | 覆盖率要求 |
|----------|------------|------------|
| 单元测试 | 100% | ≥80% |
| 集成测试 | 100% | ≥70% |
| E2E测试 | 100% | N/A |

### 失败处理标准

- 任一层测试失败，停止后续执行
- 记录失败测试详情
- 分析失败原因

## 注意事项

### 执行原则

1. **环境隔离**：测试必须在隔离环境执行
2. **可重复性**：测试结果必须可重复
3. **证据保存**：所有输出必须保存
4. **失败即停**：测试失败立即停止

- 前置任务：代码开发完成
- 技术依赖：Docker、测试环境
