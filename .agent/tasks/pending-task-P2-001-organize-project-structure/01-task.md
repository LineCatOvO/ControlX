## 背景说明

ControlX是一个使用pnpm和turbo的monorepo项目，包含apps/和packages/目录。需要整理项目文件结构，删除临时文件、冗余文件，确保目录结构标准化。

## 任务范围

### 涉及文件

| 文件路径 | 操作类型 | 说明 |
|----------|----------|------|
| apps/*/ | analyze | 应用目录 |
| packages/*/ | analyze | 包目录 |
| src/ | analyze | 源代码目录 |
| tests/ | analyze | 测试目录 |

### 命令列表

| 命令 | 类型 | 说明 |
|------|------|------|
| ls -la | 基础命令 | 查看目录结构 |
| tree -L 3 -a -I 'node_modules\|.git\|dist\|build' | 基础命令 | 生成目录树 |
| find . -name "*.tmp" -o -name "*.temp" | 基础命令 | 查找临时文件 |

### 边界约束

- **包含**：apps/、packages/、配置文件、源代码目录
- **排除**：node_modules、.git、dist、build等构建产物
