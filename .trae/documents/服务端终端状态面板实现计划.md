# 服务端终端状态面板实现计划

## 1. 实现目标
- 创建一个终端动态状态面板，显示当前客户端连接和输入状态
- 使用ANSI转义序列实现底层控制，无外部依赖
- 采用固定刷新率渲染，避免抖动
- 实现可插拔设计，通过环境变量控制启用
- 不污染业务逻辑，仅渲染当前状态

## 3. 实现步骤

### 3.1 创建终端状态面板模块
- **文件位置**：`Server/src/utils/terminalMonitor.ts`
- **核心功能**：
  - ANSI转义序列封装
  - 状态面板渲染逻辑
  - 固定刷新率控制
  - 进程退出时的清理

### 3.2 实现状态面板渲染
- **渲染内容**：
  - 客户端连接状态
  - 消息类型统计
  - 键盘、游戏手柄、鼠标、摇杆状态
  - FPS显示
- **渲染频率**：30 FPS
- **渲染方式**：
  - 清屏 + 光标归位
  - 渲染当前状态
  - 隐藏/显示光标控制

### 3.3 集成到服务端主流程
- **修改文件**：`Server/src/app.ts`
- **集成方式**：
  - 添加终端监控器初始化
  - 通过环境变量控制是否启用
  - 传递必要的状态引用

### 3.4 测试验证
- **测试场景**：
  - 正常启动服务，验证面板显示
  - 客户端连接，验证状态更新
  - 输入模拟，验证状态变化
  - 进程退出，验证资源清理

## 4. 关键代码设计

### 4.1 终端控制工具类
```typescript
class TerminalControl {
  static clearScreen(): void
  static moveCursorToTop(): void
  static hideCursor(): void
  static showCursor(): void
  static clearLine(): void
}
```

### 4.2 状态面板类
```typescript
class TerminalMonitor {
  private state: any
  private fps: number
  private intervalId: NodeJS.Timeout | null = null
  
  constructor(state: any, fps: number = 30)
  start(): void
  stop(): void
  private render(): void
  private getFormattedState(): string
}
```

### 4.3 主流程集成
```typescript
// 在app.ts中
if (process.env.INPUT_MONITOR === '1') {
  const monitor = new TerminalMonitor(inputState);
  monitor.start();
  
  // 进程退出时清理
  process.on('exit', () => {
    monitor.stop();
  });
}
```

## 5. 环境变量配置
- **INPUT_MONITOR**：设置为'1'启用终端状态面板，默认不启用

## 6. 实现细节
- 仅在非测试环境启用，避免污染测试输出
- 采用模块化设计，易于扩展和维护
- 不修改现有业务逻辑，仅读取状态
- 支持多客户端扩展（未来）

## 7. 预期效果
- 服务启动后，终端显示动态状态面板
- 实时更新当前输入状态
- 无闪烁，稳定显示
- 进程退出时自动清理，恢复终端状态

## 8. 技术栈
- Node.js + TypeScript
- 原生ANSI转义序列
- 无外部依赖

这个实现计划遵循了用户提出的核心原则：状态驱动、固定刷新率、ANSI原地渲染，并且实现了可插拔的设计，不会影响生产环境的性能。
