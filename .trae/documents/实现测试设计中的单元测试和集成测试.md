# 测试实现计划

## 一、测试辅助类（test-only helpers）

1. **RawEventCollector**

   * 实现 `PlatformAdaptationLayer.RawEventSink` 接口

   * 提供线程安全的事件收集和验证功能

   * 支持 await 条件等待特定事件

2. **PrimitiveCollector**

   * 实现 `InputAbstractionLayer.OutputSink` 接口

   * 收集和验证 PointerFrame 和 GyroFrame

   * 提供断言方法验证事件序列

3. **NDJSONParser**

   * 解析 NDJSON 格式的事件数据

   * 支持将解析后的数据喂给 InputAbstractionLayer

   * 用于回放一致性 Golden 测试

## 二、JVM 单元测试（app/src/test/）

### 1. InputAbstractionLayer Pointer 状态机测试

* **测试类**：`InputAbstractionLayerPointerTest`

* **测试方法**：

  * `testSinglePointerTapSequence`：测试单指点击序列

  * `testMoveMergeDoesNotSwallowKeyFrames`：测试 MOVE 合并不吞关键帧

  * `testMultiTouchConcurrentAndChangedIds`：测试多指并发与 changedIds

  * `testCancelSemanticsFreeze`：测试 CANCEL 语义冻结

### 2. InputAbstractionLayer 旋转归一化测试

* **测试类**：`InputAbstractionLayerRotationTest`

* **测试方法**：

  * `testRotationZeroPassThrough`：测试 rotation=0 直通

  * `testRotationMappingCorrect`：测试 rotation=90/180/270 映射正确

  * `testMetricsChangeAndSpaceUpdate`：测试 metrics 变化与 space 更新

### 3. InputAbstractionLayer Gyro 映射与精度测试

* **测试类**：`InputAbstractionLayerGyroTest`

* **测试方法**：

  * `testGyroAxisMappingFreeze`：测试 Gyro 轴映射冻结

  * `testGyroAccuracyPassthrough`：测试 Gyro 精度透传

  * `testGyroTimeNanosMonotonic`：测试 Gyro 时间戳单调性

### 4. 回放一致性 Golden 测试

* **测试类**：`InputAbstractionLayerGoldenTest`

* **测试资源**：`src/test/resources/golden/*.ndjson`

* **测试方法**：

  * `testPointerTapGolden`：测试指针点击回放一致性

  * `testPointerCancelGolden`：测试指针取消回放一致性

  * `testGyroAxisMappingGolden`：测试陀螺仪轴映射回放一致性

  * `testRotationAndTouchGolden`：测试旋转和触摸回放一致性

## 三、Instrumentation 集成测试（app/src/androidTest/）

### 1. PlatformAdaptationLayer 生命周期与输出序列测试

* **测试类**：`PlatformAdaptationLayerLifecycleTest`

* **测试方法**：

  * `testStartOverlayProducesAttachedAndMetrics`：测试 startOverlay 产生 ATTACHED + METRICS

  * `testStopOverlayProducesDetachedAndStopsSensor`：测试 stopOverlay 产生 DETACHED，且传感器停止

### 2. Touch 端到端测试

* **测试类**：`PlatformAdaptationLayerTouchTest`

* **测试方法**：

  * `testRealOverlayTouchInjection`：测试真实 overlay 触摸注入（如果权限允许）

  * `testSameLogicViewTouchCallback`：测试同逻辑 View 的触摸回调可工作

### 3. CANCEL 端到端收敛测试

* **测试类**：`PlatformAdaptationLayerCancelTest`

* **测试方法**：

  * `testStopOverlayCausesCancelOrEquivalentTermination`：测试 stopOverlay 必须导致 CANCEL 或等效终止

### 4. Raw 背压与丢弃策略测试

* **测试类**：`PlatformAdaptationLayerBackpressureTest`

* **测试方法**：

  * `testSensorFloodOnlyDropsSensor`：测试 sensor 洪泛时只丢 sensor

### 5. 联合集成测试

* **测试类**：`PlatformToInputAbstractionIntegrationTest`

* **测试方法**：

  * `testRealInputProducesValidPrimitives`：测试真实输入 → primitives 不违背契约

## 四、测试数据准备

1. 创建 Golden 测试所需的 NDJSON 数据文件
2. 准备旋转测试的坐标映射数据
3. 准备陀螺仪轴映射测试数据

## 五、实现顺序

1. 先实现辅助类（RawEventCollector、PrimitiveCollector、NDJSONParser）
2. 然后编写 JVM 单元测试
3. 最后编写 Instrumentation 集成测试
4. 运行测试验证实现正确性

## 六、测试框架与工具

* **JVM 单元测试**：JUnit 5 + AssertJ

* **Instrumentation 测试**：AndroidJUnit4 + ActivityScenario

* **模拟工具**：Mockito（用于模拟依赖）

* **断言库**：AssertJ（用于流畅的断言语法）
