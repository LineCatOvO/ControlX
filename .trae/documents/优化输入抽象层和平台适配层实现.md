# 实现计划

## 1. 重写 PlatformAdaptationLayer.java

### 1.1 核心设计
- 实现为 `final` 类，不继承任何其他类
- 内部定义所有需要的数据结构（RawWindowEvent、RawPointerEvent、RawSensorEvent、RawDropEvent）
- 实现文档中定义的 `RawEventSink` 接口
- 管理 Overlay Window、触摸事件、陀螺仪事件和前台服务生存
- 实现 Raw 事件背压机制

### 1.2 主要组件
- Overlay Window 管理：创建和管理系统悬浮窗
- 触摸事件处理：接收和处理 Android 触摸事件
- 陀螺仪事件处理：接收和处理陀螺仪传感器事件
- 前台服务管理：确保服务在前台运行
- Raw 事件生成：将平台事件转换为 Raw 事件并通过回调输出
- 背压机制：实现有界队列，确保关键事件不丢失

## 2. 重写 InputAbstractionLayer.java

### 2.1 核心设计
- 实现为 `final` 类，不继承任何其他类
- 内部定义所有需要的数据结构（PointerFrame、PointerState、GyroFrame）
- 实现文档中定义的 `OutputSink` 接口
- 接收 Raw 事件，进行归一化、状态机管理和事件合并
- 输出稳定、可回放的输入原语

### 2.2 主要组件
- Metrics 跟踪：保存最新的宽度、高度和旋转信息
- 坐标归一化：将 Raw 坐标转换为 [0,1] 范围的归一化坐标
- Pointer 状态机：管理指针的 DOWN/MOVE/UP/CANCEL 状态
- MOVE 合并：将高频 MOVE 事件合并为目标频率（60Hz）
- 陀螺仪处理：将 Raw 陀螺仪数据映射为 yaw/pitch/roll 速率

## 3. 数据流设计

```
Android System
   │
   ▼
PlatformAdaptationLayer
   │   （Raw Events via RawEventSink）
   ▼
InputAbstractionLayer
   │   （Primitives via OutputSink）
   ▼
Upper Layer
```

## 5. 关键技术点

- **坐标归一化**：将不同旋转方向的屏幕坐标转换为自然竖屏坐标，然后归一化到 [0,1] 范围
- **Pointer 状态机**：确保指针事件的正确处理和状态维护
- **MOVE 合并**：使用固定频率合并 MOVE 事件，减少上层处理压力
- **轴映射**：正确映射陀螺仪的原始数据到 yaw/pitch/roll 速率
- **背压机制**：实现有界队列，确保关键事件不丢失，非关键事件可适当丢弃
